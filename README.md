Soy estudiante de **Ingeniería de Sistemas** en la **Universidad UPeU**, apasionado por el **desarrollo Full Stack** y las **aplicaciones móviles**.  
Me gusta construir sistemas escalables, eficientes y bien estructurados, aplicando buenas prácticas de desarrollo y arquitectura de software.  

Actualmente me enfoco en el desarrollo con **Spring Boot** para el backend y **Angular** para el frontend, integrando APIs REST y trabajando con bases de datos relacionales y no relacionales.  
Además, estoy en constante aprendizaje para mejorar mis habilidades técnicas y contribuir en proyectos reales y colaborativos.
